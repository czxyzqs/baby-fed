# 补剂暂停与恢复

- 在首页补剂卡片的齿轮中打开“补剂设置”，通过每种补剂的开关暂停或恢复，点击“保存”后生效；取消不会保存更改。
- 暂停后，不再计入当前计划的应服次数、首页待办或定时提醒；补剂名称、稳定 ID、频率、起始日期及每天的服用时段均保留。
- 已有服用记录不会被删除或改写，喂养分析仍统计实际记录；仍允许手动补记或编辑历史记录。
- 恢复后沿用原来的日历计划，不重新计算起始日期，也不会补发暂停期间往日的提醒。当天未完成且已到时的时段按现有提醒规则处理。
- 交替组内每种补剂有独立开关。暂停某成员不移除该成员、不把它的日期转给其他成员；恢复后仍按原来的轮换日期服用。
- 设置中新增布尔字段 `enabled`，旧配置未提供时默认启用。保存接口拒绝非布尔值，无需迁移历史记录。
- 保存失败会保留当前设置草稿并显示错误，可直接重试。其他设备通过已有首页刷新机制更新待办。

## 验收

- 使用独立数据副本验证旧配置默认启用、关闭/保存/重载/恢复、取消及保存失败重试。
- 覆盖每日、隔日、每 N 天、每周、交替组和不提醒/首页待办/定时提醒三种模式。
- 暂停仅影响被暂停成员；恢复后当日已完成次数不丢失，历史记录文件内容保持不变。
- 编辑暂停的普通补剂或交替组后保留开关状态；新补剂默认启用。
- 实际浏览器验证电脑/手机开关可操作、键盘可切换、无脚本错误、首屏正常显示。
