# 补剂设置弹窗设计

## 概述

为婴儿追踪应用新增独立的补剂添加弹窗，替代原有的 prompt 方式，支持完整的频率设置。

## 频率选项

| 选项 | 说明 | 附加数据 |
|------|------|----------|
| 每天 | 每天都吃 | - |
| 自定义 - 按天 | 每N天吃一次 | intervalDays: 2 |
| 自定义 - 按周 | 指定周几吃 | customDays: [1,3,5] |
| 交替组 | 多种补剂轮流吃 | groupId + startDate + startIndex |

### 频率类型说明

- **daily**: 每天吃
- **custom + interval**: 每隔 N 天吃（intervalDays）
- **custom + weekdays**: 按周几吃（customDays, 周一=1）
- **alternating**: 属于交替组，由 groupId 指定组，组内按顺序轮转

```
│                             │

│  ┌─────┬─────┬─────┬─────┐ │

│                             │

```

## 图标选择器

点击图标区域弹出网格选择器，显示常用表情符号：
💊 ☀️ 🌟 🫙 🔩 🐟 💪 🧠 🍎 💜

## 交互流程

1. 点击"+ 添加补剂" → 打开独立弹窗
2. 填写名称（必填）、选择图标、选择频率类型
3. 根据频率类型显示/隐藏对应输入框
4. 点"确认添加" → 补剂添加到列表，弹窗关闭
5. 点"取消" → 弹窗关闭，无变化
