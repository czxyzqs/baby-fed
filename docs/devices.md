# 设备兼容基准

> 用户实际使用的设备与 UI 改动必须覆盖的视口。改动涉及弹窗/抽屉/布局时，发布前按此清单过一遍。

## 家里的设备

| 设备 | 视口（竖屏 CSS px） | 说明 |
|---|---|---|
| iPhone 15 Pro Max | 430 × 932（DPR 3） | 主力记录设备，弹窗类改动必须在此宽度验证 |
| iPad（型号待补） | ≥768 × 1024 | 历史提交处理过 iPad 兼容（原生时间轮盘 27acd30、平板抽屉 600px/620px 24e7115） |

> 2026-11-11 补记：此前文档只覆盖 320/390/1024px，漏了 430 宽（Plus/Max 系列），「＋加一个」抽屉未在此宽度验证过。用户设备清单有变时更新本表。

## UI 验证视口清单

| 视口宽 | 代表设备 | 关注点 |
|---|---|---|
| 320 | iPhone SE | 最窄屏：换行、chips 折行、文字截断 |
| 390 | iPhone 15/15 Pro | 标准宽度基线 |
| 430 | iPhone 15 Pro Max / Plus | 最宽手机：抽屉 560px 上限触顶、留白是否过大 |
| 768 / 820 | iPad 竖屏 | 触发平板断点（≥768px） |
| 1024+ | 桌面 / iPad 横屏 | 弹窗居中、最大宽度封顶 |

通用要求（沿用既有约定）：

- 触控目标 ≥44px（fp-picker-chips .fma-chip 已放大）
- 输入框 font-size ≥16px，防 iOS 聚焦自动放大整页（fma-search）
- 底部抽屉留 `env(safe-area-inset-bottom)`，含手势条设备不贴边
- 弹窗骨架固定高度（dvh 封顶），键盘弹起尺寸不跳
- `body.elder` 老年模式单独过一遍横向溢出
