# 页面资源与响应缓存

- `templates/` 只保留页面结构和动态初始化数据；主要样式与逻辑分别放在 `static/css/` 和 `static/js/`。
- JavaScript 使用 `defer` 加载，页面解析完成后执行，保留现有按钮和初始化顺序。
- 模板通过 `url_for('static', filename=...)` 引用资源。应用启动时计算文件内容的 SHA-256，并自动附加 `v` 版本参数。
- 版本匹配的 CSS/JS 返回 `Cache-Control: public, max-age=31536000, immutable`；无版本或版本不匹配的资源需要重新验证。
- HTML 和 JSON 数据响应使用 `no-cache, no-store, must-revalidate`，不对喂养记录进行长期缓存。
- 支持 gzip 的客户端可获得压缩后的 HTML、JSON、CSS 和 JavaScript。小于 500 字节的响应、部分内容和其他流式响应不压缩。
- 页面资源来自本服务，不依赖外部字体或 CDN。

## 喂养与睡眠分析

- 默认仍展示今天；切换日期才请求对应日期的数据，不再通过 `/api/records` 下载全部历史明细。
- `GET /api/analysis/feeding?date=YYYY-MM-DD&timezone=Asia%2FShanghai` 返回所选当天的记录及七天奶量汇总。当天记录保留各类型及未来时间，展示时继续按当前时间截断。
- `GET /api/analysis/sleep` 接受相同参数，只返回当天已完成睡眠区间、七天时长/次数汇总、历史睡姿累计时长，以及仍未结束的入睡时间。
- `timezone` 使用浏览器的 IANA 时区，省略时使用上海时区。日期睡眠按浏览器时区解析无时区时间；喂养和历史睡姿继续使用原有北京时间口径。已完成的跨日睡眠整体归属入睡日期，不截断到当天。
- 未结束的睡眠在前端每次渲染时更新时长，缓存不固化结束时间；历史未结束睡眠仍按入睡日末截断，历史睡姿则累计到当前时间。
- 服务端首次或记录版本变化后读取月度 JSON 分片建立索引，每个进程最多缓存四份按版本、分析类型、时区、查询日期范围区分的索引。喂养分析只加载所选日期和七天趋势涉及的月份；睡眠分析仍合并全部历史，以保留跨月配对、未结束睡眠及历史睡姿口径。历史明细不会传给分析弹窗。
- 前端最多缓存十四份日期响应；再次打开/重访日期先检查 `/api/records/version`，版本变化则重新拉取该日期。相同请求合并，快速切换日期只呈现最后选择的结果；网络失败显示重试入口，不将旧结果冒充新日期。
- 记录版本来自持久化事务清单，不再使用文件修改时间和大小。分析响应在统一存储锁内取得数据和版本；记录新增、修改、删除和备份恢复都会生成新版本，使不同进程和前端缓存失效。存储损坏或 I/O 失败返回 503，不将损坏文件当作空记录。
- AI 喂养分析仅提交所选日期，由服务端获取该日记录；其他功能及原全量记录接口保持兼容。

## 月度 JSON 存储

- 记录按北京时间的发生月份存入 `data/records/YYYY-MM.json`，原始记录字段和时间文本保持不变。
- 列表日期筛选先选择相关月份，再沿用原有时间字符串前缀筛选规则；带时区记录可能落在相邻月份，边界查询会补读相关分片。
- 新增、编辑、删除只重写涉及的月份，不再重写整份历史。第一版的 ID 查重、编辑和删除定位仍可能扫描历史分片，尚未增加独立 ID 索引。
- 写入使用跨线程、跨进程文件锁，以及临时文件、`fsync`、原子替换和可重放事务日志。跨月编辑、设置、提醒去重和恢复均由同一存储层管理。
- 完整备份默认在有写入时按一小时间隔触发，不再每次保存都复制全部历史；快照同时包含记录与设置。备份策略、迁移、恢复及回滚注意事项见 `docs/storage.md`。

## 更新与部署

首次从单文件存储升级时，先按 `docs/storage.md` 停止旧写入者、备份并迁移，不能让旧版与新版同时访问数据目录。完成存储升级后，日常静态资源更新使用 `docker compose up -d --build app` 重新构建和部署。Docker 镜像包含 `static/`，新进程会生成新的资源版本号；不要只修改运行中容器的资源文件。

重新打开页面会获取最新 HTML 和对应版本的资源。未修改的静态资源可以继续使用浏览器缓存。

## 验证

- 用浏览器正常访问首页和记录页，确认页面显示、按钮、记录操作和分析弹窗正常。
- 检查资源地址的 `v` 参数及响应的 `Cache-Control`。
- 请求时携带 `Accept-Encoding: gzip`，检查较大响应的 `Content-Encoding: gzip` 和 `Vary: Accept-Encoding`。
- 使用相同浏览器再次访问，静态资源应命中缓存，动态 HTML 和记录接口仍应访问服务器。
- 打开喂养/睡眠分析和切换日期，确认默认今天、日期统计与旧版一致，且网络面板不出现全量 `/api/records` 请求。
- 覆盖跨午夜、月末、年末、夏令时、未结束睡眠及重复入睡/醒来事件，核对每日区间、七天趋势与历史睡姿。
- 在独立数据副本中增删改记录，确认日期缓存失效；快速切换日期、模拟接口失败，确认没有旧日期覆盖及错误数据展示。
- 不拦截外部资源进行真实浏览器首屏加载检查，记录首次内容绘制并人工查看桌面/手机截图，避免遗漏白屏问题。
